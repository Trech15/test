CalmCampus individual Flutter test case files

Files:
- case1.dart through case71.dart (one test file per case)
- CASE-039 is included using the uploaded working example.
- Other cases are scaffolded and intentionally marked skipped until screen
  imports, UI locators, steps, and assertions are implemented.

Run a single case from the frontend project:
  flutter test test/case2.dart --reporter expanded

Before running:
Copy the case*.dart files into your Flutter project's test/ folder.
Keep your existing test_helpers.dart in that folder.
